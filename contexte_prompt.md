# CONTEXTE PROJET — ZEPHYR (PROTOTYPE AVANCÉ AVEC ADMIN)

## 1. OBJECTIF

Construire un prototype avancé du site Zephyr avec :

- frontend premium
- expérience utilisateur fluide
- simulation d’un back-office (admin panel)

⚠️ Ce projet est un prototype, pas une application production.

---

## 2. STACK TECHNIQUE

- React (Vite)
- React Router
- Tailwind CSS
- Framer Motion
- Données simulées (JSON + localStorage)

---

## 3. OBJECTIFS PRODUIT

Le site doit :

- présenter les services
- exposer un portfolio
- intégrer un blog
- permettre la prise de contact
- simuler une gestion de contenu via un admin panel

---

## 4. STRUCTURE DU SITE

### Pages publiques :

- `/` → Home
- `/services`
- `/portfolio`
- `/blog`
- `/contact`

---

### Pages admin (simulation) :

- `/admin`
- `/admin/projects`
- `/admin/blog`
- `/admin/testimonials`

---

## 5. ADMIN PANEL (SIMULÉ)

### Fonctionnalités :

- ajouter / modifier / supprimer :
  - projets
  - articles blog
  - témoignages

- formulaires simples

- mise à jour immédiate UI

---

### Stockage :

- données en JSON local
- persistance simulée avec localStorage

⚠️ Ne pas implémenter de backend réel.

---

## 6. EXPÉRIENCE UTILISATEUR

- navigation fluide (React Router)
- scroll management
- transitions animées entre pages
- design épuré et premium

---

## 7. ANIMATIONS

- Framer Motion
- effets au scroll
- transitions de pages
- animations légères et maîtrisées

---

## 8. DESIGN SYSTEM (OBLIGATOIRE)

### Couleurs :

- #1A3AFF (primary)
- #0A1628 (dark)
- #000000

### Gradients :

- #1A3AFF → #00B4FF → #00E5FF

---

### Typographie :

- Orbitron (titres)
- Inter (texte)

---

### UI :

- boutons (primary / ghost / dark)
- border radius (4 / 8 / 12 / 24px)

---

## 9. TON

- direct
- technique
- orienté résultats
- sans jargon inutile

---

## 10. CONTRAINTES

- pas de backend
- pas d’auth complexe
- code structuré et évolutif
- design prioritaire

---

## 11. OBJECTIF FINAL

Créer un prototype qui donne l’impression :

“Ceci est une vraie plateforme digitale prête à être utilisée”

---

FIN DU CONTEXTE
